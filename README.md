# Token School 🎓

> **CBSE Classes 6–12 | Learn. Lead. Grow.**

A stunning, premium single-page educational website for CBSE students, built for **Token School**.

## 🌟 Features

- **7 Class Cards** (Classes 6–12) with CBSE-aligned syllabus
- **10 Subjects** — Maths, Science, Physics, Chemistry, Biology, SST, English, CS, Economics, Accountancy
- **Animated hero** with particle canvas, typewriter effect, and floating stat cards
- **Interactive features** — scroll reveal animations, counter animations, testimonial slider
- **Pricing section** — Monthly/Annual toggle with 40% savings
- **Fully responsive** — mobile, tablet, desktop
- **Dark mode** — premium deep purple/blue color palette

## 🚀 Deploy to Vercel

1. Push this repo to GitHub
2. Import in [Vercel](https://vercel.com/new) → select repo → deploy (no build step needed)
3. That's it! Live in seconds.

## 🎨 Design System

- **Font**: Outfit (display) + Inter (body)
- **Colors**: Deep navy/purple dark mode with purple/teal/pink accents
- **Effects**: Glassmorphism, particle canvas, scroll reveal, parallax
