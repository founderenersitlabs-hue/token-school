Core Topics

AI Topics Covered Across All Classes

Every major domain of Artificial Intelligence — built progressively from Class 6 to Class 12.

🤖

Introduction to AI

What is AI, how machines think, early history, types of AI (narrow, general), and AI all around us in daily life.

Class 6
📐

Algorithms & Logic

Problem solving, decision trees as flowcharts, rule-based systems, computational thinking and step-by-step instructions.

Class 6–7
📊

Data & Patterns

What data is, why it matters for AI, patterns and predictions, data collection, cleaning, and visualisation basics.

Class 7–8
🧠

Machine Learning

Supervised and unsupervised learning, training and testing, regression, classification, clustering — built from intuition up.

Class 7–12

Python for AI

Python programming from scratch, NumPy, Pandas, Matplotlib, Scikit-learn, and introduction to PyTorch and TensorFlow.

Class 9–12

Neural Networks

Perceptrons, multi-layer networks, activation functions, backpropagation, training dynamics, and practical implementations.

Class 10–12

Computer Vision

Convolutional Neural Networks, image classification, object detection, face recognition, and real-world CV applications.

Class 10–12
💬

Natural Language Processing

Text analysis, tokenization, word embeddings, sentiment analysis, chatbots, transformers, and how ChatGPT works.

Class 10–12
✨

Generative AI & LLMs

GANs, diffusion models, VAEs, Large Language Models, prompt engineering, fine-tuning, and responsible GenAI use.

Class 12
🎮

Reinforcement Learning

Reward systems, agents and environments, Q-learning, policy gradients, and famous RL applications (AlphaGo, games).

Class 12
⚖️

Bias, fairness, privacy, deepfakes, AI regulation, digital rights, and how to build responsible AI systems.
